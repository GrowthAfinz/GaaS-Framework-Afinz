# Funil de Aquisição (leitura ponta a ponta)

**Definição:** as taxas médias do funil de aquisição fria, ponta a ponta.

> 📊 Snapshot 2026-06-08 — etapa Aquisicao.

| Etapa | Taxa |
|---|---|
| Entrega | 90,0% |
| Abertura | 9,2% |
| Proposta | 11,8% |
| Aprovação | 58,0% |
| Conversão | 6,7% |

## Leitura
O funil é mensurado de ponta a ponta — capacidade que planilha não dava. O gargalo de aquisição fria está no topo (abertura 9,2%) e na proposta. A aprovação alta (58%) indica que o público qualificado responde; o desafio é finalização (característica do mercado fintech — ver [[Base-Acionável]], regra "conversão zero é válida").
