# Tabela: dispatch_descriptions

**Definição:** **descrições livres por disparo** — texto explicativo anexado a um `activity_name` (PK), fora dos campos estruturados de [[activities]].

## Contexto
Permite registrar contexto qualitativo de um disparo (o "porquê" que não cabe nas 49 colunas). Campos: `activity_name`, `description`, `updated_at`. Ligado pela [[Taxonomia-Activity-Name]].
