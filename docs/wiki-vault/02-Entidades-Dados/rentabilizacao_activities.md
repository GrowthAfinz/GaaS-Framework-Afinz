# Tabela: rentabilizacao_activities

**Definição:** disparos de **rentabilização** — schema **idêntico** ao de [[activities]], com FK para ela.

Fora do foco de aquisição, mas serve de **referência estrutural**: confirma que o modelo de "atividade" é reutilizável e que aquisição vs rentabilização diferem por *dados*, não por *modelo*. É também a fonte futura para a curva de [[CAC-Ótimo]] (rentabilidade por safra).
