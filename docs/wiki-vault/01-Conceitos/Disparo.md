# Disparo

**Definição:** instância única de envio de uma comunicação. É a unidade-base de dados — uma linha na tabela [[activities]].

## Contexto
Cada disparo é identificado pela [[Taxonomia-Activity-Name]]. Carrega público, canal, oferta, custo e o funil completo de KPIs. **Disparo ≠ [[Template]]:** o disparo é o evento de envio; o template é o conteúdo enviado.

> 📊 Snapshot 2026-06-08 — 4.606 disparos registrados (jan/25–jun/26), todos com status `Realizado`.
