# Agentes neste checkout do GaaS

Para atualizar fontes, Fila, notificações e notas de resultado, abrir `.claude/skills/gaas-growth-loop-operator/SKILL.md`, canônica para Codex e Claude. O processamento depende de comando explícito; notas são contribuições revisadas e depois sincronizadas com o vault.

Seguir também as instruções do projeto pai quando disponíveis. Conversar em PT-BR, com linguagem de colega de trabalho.

Para inventariar ou receber dados brutos de Seguros, portfólio, CP e Pool para relatórios, ler `.claude/skills/gaas-portfolio-data-ingest/SKILL.md`. O catálogo distingue tabelas existentes de propostas e etapas ainda não implementadas. O fluxo recorrente é de inclusão: chaves existentes e períodos encerrados são ignorados e auditados, sem sobrescrita automática. Os XLSX/PPTX de referência são modelos de saída.

Ao receber pedido para rodar a fila de investigações Growth, abrir a skill canônica compartilhada por Codex e Claude em `.claude/skills/gaas-growth-investigation/SKILL.md` e seguir seu contrato. Não substituir pelo publicador legado de `crm_insights`.

A plataforma não chama API de IA para este fluxo. Nenhuma alteração de fonte, campanha, orçamento ou publicação externa é autorizada pelo processamento dessa fila.

Para criar ou revisar notas de estratégia e sua apresentação no GaaS, usar `.claude/skills/gaas-estrategias-implementaveis/SKILL.md`: a nota Visa é modelo de narrativa, profundidade, fluxos e fichas técnicas, além da aparência.
